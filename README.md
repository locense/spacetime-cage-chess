# 时空牢笼棋 MVP

此仓库保存了时空牢笼棋 Web MVP 的可恢复备份。

- `spacetime-cage-chess-mvp.zip`：源码、测试、工作区配置的 ZIP 快照。
- `spacetime-cage-chess-mvp.bundle`：包含完整 Git 历史和 `main` 提交 `e31bf5c` 的 Git bundle。

恢复源码：解压 ZIP；或执行 `git clone spacetime-cage-chess-mvp.bundle restored-project`。

验证命令：`pnpm install && pnpm test && pnpm build`。
